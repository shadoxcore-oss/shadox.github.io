# مقدمة إلى Bash
## 1.ما هو Bash؟

ببساطة **Bash** اختصار لـ **Bourne Again SHell**.

وهو نوع من أنواع `Shell` الموجودة والمستخدمة في أنظمة Linux، وهو عبارة عن مفسر أوامر يمكن من خلاله القيام بمجموعة من العمليات المختلفة، مثل تشغيل البرامج، والتعامل مع الملفات والمجلدات، وكتابة السكريبتات لأتمتة مهام معينة، أو بناء أدوات `CLI`.

يستخدم Bash على العديد من توزيعات Linux المختلفة مثل ديبيان و فيدورا و أرش و غيرها ... 

## 2. إنشاء ملف Bash Script

لإنشاء ملف Bash Script أو الانتقال إلى ملف موجود يمكننا استخدام `nano` بالشكل التالي:

```bash
nano <filename>
```

مثلاً:

```bash
nano myscript.sh
```

بعد فتح الملف يمكننا البدء بكتابة أوامر Bash بداخله.

## 3. كتابة سطر `Shebang`

### 3-1. ما هو `Shebang`؟

ببساطة، `Shebang` هو السطر الموجود عادةً في أول سطر من ملف السكريبت، ويحدد للنظام البرنامج الذي يجب استخدامه لتفسير وتشغيل الملف.

في حالة Bash نكتب:

```bash
#!/usr/bin/env bash
```

ويتكون هذا السطر من عدة أجزاء:

 - الجزء -->> `#!`  العلامة التي تحدد أن هذا السطر هو `Shebang`
 
- الجزء -->> `/usr/bin/env`  يبحث عن البرنامج المطلوب داخل `PATH` 

- الجزء -->> `bash`  البرنامج الذي سيتم استخدامه لتفسير السكريبت.

### 3-2. ماذا نكتب بعد `Shebang`؟

بعد كتابة `Shebang` نبدأ بكتابة الأوامر التي نريد من السكريبت تنفيذها:

```bash
#!/usr/bin/env bash

# كتابة الأوامر التي نريد من السكريبت تنفيذها
```

## 4. كتابة أول سكريبت `Hello, World`

### 4-1. الأمر `echo`

لطباعة شيء ما في الطرفية نستخدم الأمر `echo` بالشكل التالي:

```bash
echo "<something>"
```

مثلاً:

```bash
echo "Hello, World"
```

### 4-2. إنشاء سكريبت يطبع `Hello, World`

أولًا ننشئ سكريبت أو ننتقل إلى سكريبت موجود:

```bash
nano myscript.sh
```

ثم نكتب بداخله:

```bash
#!/usr/bin/env bash

echo "Hello, World"
```

بعد الانتهاء من الكتابة، لحفظ التغييرات في `nano` نضغط على `Ctrl + O` و بعدها للخروج `Ctrl + X`



### 4-3. إعطاء صلاحية التنفيذ

حتى نستطيع تشغيل السكريبت مباشرةً باستخدام:

```bash
./myscript.sh
```

نحتاج إلى إعطائه صلاحية التنفيذ.

نستخدم:

```bash
chmod +x <filename>
```

وفي حالتنا:

```bash
chmod +x myscript.sh
```

### 4-4. تشغيل السكريبت

بعد إعطاء السكريبت صلاحية التنفيذ يمكننا تشغيله باستخدام:

```bash
./<filename>
```

وفي حالتنا:

```bash
./myscript.sh
```

و بعدها سيتم طباعة :

```text
Hello, World
```

### 4-5. تشغيل السكريبت من أي مكان

يمكننا جعل السكريبت أكثر عملية بحيث نستطيع تشغيله من أي مسار في الطرفية.


أولا ننشئ المسار الذي نريد وضع سكريبتاتنا بداخله

```bash
mkdir -p <Path>
```

في حالتنا خلينا ننشئ ده مسار :
```bash
mkdir -p ~/my-scripts
```

بعد ذلك ننسخ السكريبت إلى مسار مراد وضع سكريبتاتنا بداخله و ذلك بهذه الصيغة :

```bash
cp <filename> <Path>
```

وفي حالتنا:

```bash
cp myscript.sh ~/my-scripts
```

ثم نحتاج إلى أن يكون مسارنا موجودا بداخل متغير البيئة `PATH` و ذلك سهل للغاية كل ما عليك هو إظهار الملفات المخفية و بعدها البحث عن  `.bashrc` و ثم الضغط عليه مرتين ليتم فتحه

و بداخله تقوم بلصق سطر بصيغة تالية :

```bash
export PATH="$HOME/path:$PATH"
```

في حالتنا :
```bash
export PATH="$HOME/my-scripts:$PATH"
```

و ضغط على `Ctrl+S` لحفظ التغييرات 

بعد حفظ التغييرات  يمكن إعادة تحميلها في الجلسة الحالية باستخدام:

```bash
source ~/.bashrc
```

بعد ذلك، إذا كان السكريبت قابلًا للتنفيذ، يمكننا تشغيله من أي مكان بكتابة اسمه:

```bash
namescript
```

في حالتنا :
```bash
myscript.sh
```

> **ملاحظة:** وجود السكريبت داخل `PATH` لا يكفي وحده. يجب أن يكون السكريبت قابلًا للتنفيذ و يمكن فعل ذلك بصيغة التالية :

```bash
chmod +x ~/path/namescript
```

بحالتنا :

```bash
chmod +x ~/my-scripts/myscript.sh
```

> **ملاحظة:** يمكننا تغير اسم سكريبت إلى `myscript` بعدها كل ما علينا فعله هو كتابة `myscript` على الطرفية و هذا يجعل سكريبت الخاص بنا أكثر إحترافية 
## 5. طريقة ثانية لتشغيل السكريبت

هناك طريقة أخرى لتشغيل Bash Script، وهي استخدام برنامج `bash` مباشرةً.

### 5-1. تشغيل سكريبت بدون صلاحيات التنفيذ أو `Shebang`

لنقل أننا نريد كتابة سكريبت يطبع:

```text
Hello, World
```

يمكننا إنشاء الملف:

```bash
nano myscript.sh
```

ثم كتابة:

```bash
echo "Hello, World"
```

لاحظ أننا لم نكتب `Shebang`.

بعد ذلك يمكننا تشغيل السكريبت باستخدام:

```bash
bash myscript.sh
```

في هذه الحالة نحن نحدد بأنفسنا البرنامج الذي سيقوم بتفسير السكريبت، وهو:

```text
bash
```

لذلك لا نحتاج إلى:

```bash
#!/usr/bin/env bash
```

ولا نحتاج إلى إعطاء الملف صلاحية التنفيذ باستخدام:

```bash
chmod +x
```

طالما أننا نشغله بهذه الطريقة:

```bash
bash myscript.sh
```

### 5-2. أي طريقة نستخدم؟

كل طريقة لها استخداماتها.

إذا كنت تريد مشاركة سكريبت بحيث يستطيع المستخدم تشغيله مباشرةً:

```bash
./myscript.sh
```

أو إستخدامه من أي مسار على الطرفية :
```bash
myscript
```

فمن الأفضل إستخدام الطريقة الأولى 

أما إذا كنت تريد فقط تشغيل سكريبت Bash بنفسك، فيمكنك استخدام:

```bash
bash myscript.sh
```

بدون الحاجة إلى صلاحية التنفيذ أو `Shebang`.

## تطبيق عملي

- قم بإنشاء ملف باسم `name.sh` مهمته كتابة جملة ترحيبية `Hello , Yourname` 

- بعدها إجعله قابلا للتفيذ و قم بتشغيله

- الآن قم بإنشاء مسار `banana` و قم بوضع سكريبت الخاص بك هناك و غير اسمه إلى `name`

- بعدها إجعل ملف قابلا لتشغيل من أي مسار على الطرفية 

- و بعدها جرب القيام بنفس الأمر بإستخدام الطريقة الثانية
