# المتغيرات Variables

## 1. ما هي المتغيرات؟

المتغير هو اسم نستخدمه لتخزين قيمة معينة بشكل مؤقتا  في الذاكرة ، حتى نستطيع استخدامها لاحقا داخل السكريبت

مثلا:

```bash
name="shadox"
```

هنا:

- `name` → اسم المتغير.
    
- `shadox` → القيمة المخزنة في المتغير.
    

وللوصول إلى قيمة المتغير واستخدامها، نضع الرمز `$` قبل اسم المتغير هكذا :

```bash
echo "$name"
```

بالتالي السكريبت بيكون كذه :

```bash
name="shadox"
echo "$name"
```

الناتج:

```text
shadox
```

---

## 2. لماذا نحتاج إلى المتغيرات؟

تسمح لنا المتغيرات بتخزين قيمة ما في اسم معين ، ثم استخدام تلك القيمة في أكثر من مكان داخل السكريبت.

وبالتالي، إذا احتجنا إلى تغيير هذه القيمة، يمكننا تعديلها في مكان واحد بدلًا من البحث عنها وتغييرها في جميع الأماكن التي استخدمت فيها.

مثلاً:

```bash
name="shadox"

echo "Hello $name"
echo "Welcome $name"
```

الناتج:

```text
Hello shadox
Welcome shadox
```

ولنفترض أننا نريد تغيير الاسم إلى `Ahmed`.

بدلًا من تعديل كل سطر يستخدم الاسم، يمكننا فقط تغيير قيمة المتغير:

```bash
name="Ahmed"

echo "Hello $name"
echo "Welcome $name"
```

الناتج:

```text
Hello Ahmed
Welcome Ahmed
```

و ستتضح فائدة وجود هذه المتغيرات عندما تبدأ بكتابة سكريبتات أطول وأكثر تعقيدا ، حيث يمكن أن تستخدم نفس القيمة في العديد من الأماكن و تغييرها من مكان واحد

---

# 3. قواعد تسمية المتغيرات

عند إنشاء متغير في Bash، توجد بعض القواعد التي يجب الالتزام بها.

## 3-1. الأحرف المسموح بها

يمكن أن يحتوي اسم المتغير على:

- الأحرف الإنجليزية الصغيرة: `a-z`
    
- الأحرف الإنجليزية الكبيرة: `A-Z`
    
- الأرقام: `0-9`
    
- الشرطة السفلية: `_`
    

مثلاً:

```bash
user_name="shadox"
```

اسم المتغير `user_name` صحيح.

أما استخدام بعض الأحرف الخاصة في اسم المتغير فهو غير صحيح، مثل:

```text
+  =  @  é  &  -  !  %
```

مثلاً:

```bash
user-name="shadox"
```

هذا غير صحيح لأن `-` ليست من الأحرف المسموح بها في أسماء المتغيرات.

---

## 3-2. لا يمكن أن يبدأ اسم المتغير برقم

لا يمكن أن يبدأ اسم المتغير برقم، ولكن يمكن استخدام الأرقام في منتصف الاسم أو في نهايته.

صحيح:

```bash
user1="shadox"
version2="Bash"
user2026="shadox"
```

غير صحيح:

```bash
1user="shadox"
2version="Bash"
```


---

## 3-3. اختر أسماء ذات معنى

من الأفضل أن يكون اسم المتغير واضحًا ويعبّر عن القيمة التي يخزنها.

فبدلًا من:

```bash
x="shadox"
```

يفضل استخدام:

```bash
username="shadox"
```

وبدلًا من:

```bash
x=20
```

يفضل:

```bash
age=20
```

بهذه الطريقة يصبح السكريبت أسهل في القراءة والفهم، خصوصًا عندما يكبر المشروع ويحتوي على عدد كبير من المتغيرات.

مثال:

```bash
username="shadox"
email="shadox@example.com"
age=20

echo "Username: $username"
echo "Email: $email"
echo "Age: $age"
```

من خلال أسماء المتغيرات يمكننا معرفة الغرض من كل قيمة دون الحاجة إلى البحث في باقي السكريبت.

---

# 4. الخلاصة

- بخصوص تسمية المتغيرات يسمج بحروف الإنجليزية فقط سواء الكبيرة أو الصغيرة و `_` بالإضافة للأرقام بشرط أن يبدأ المتغير بحرف أو `_`
- تفيدنا المتغيرات في حالة أردنا أن نستخدم نفس القيمة في أماكن معينة من سكريبت مع إمكانية تغيير قيمتها من مكان واحد
- نستخدم الرمز `$` عندما نريد الحصول على قيمة المتغير مثل `Value$`
