# المدخلات

## 1. ما هي المدخلات؟

المدخلات هي ببساطة استقبال قيمة من المستخدم بدلًا من كتابتها مباشرة داخل السكريبت.

على سبيل المثال، يمكننا إنشاء برنامج يطلب من المستخدم إدخال رقم معين، ثم يقوم بطباعة رسالة تحتوي على الرقم:

```text
The number is X
```

حيث `X` هي القيمة التي أدخلها المستخدم.

---

## 2. استقبال مدخلات المستخدم

خلينا ننشئ ملفًا باسم `input.sh`، ثم نعطيه صلاحيات التنفيذ:

```bash
touch input.sh
chmod +x input.sh
```

**ملاحظة :**
يُستخدم أمر `touch` لإنشاء ملف جديد إذا لم يكن موجودا، ويمكن استخدامه أيضا إنشاء عدة ملفات:

```bash
touch <file1> <file2> <file3>
```

مثلًا:

```bash
touch input.sh test.sh script.sh
```

بعد ذلك نريد من السكريبت الخاص بنا أن يستقبل اسمًا من المستخدم ثم يقوم بعرضه.

يمكننا فعل ذلك باستخدام `read`:

```bash
#!/usr/bin/env bash

read name
echo "Hello, $name"
```

**ملاحظة :**
إذا كنت تستخدم محرر النصوص `nano`، فتذكر:

- `Ctrl + O` لحفظ التغييرات.
    
- `Ctrl + X` للخروج من المحرر.
    

---

### 2-1.استخدام `read`

هذا الجزء هو المسؤول عن استقبال القيمة من المستخدم:

```bash
read name
```

فعندما يصل السكريبت إلى `read`، فإنه ينتظر المستخدم حتى يكتب قيمة ثم يضغط `Enter`.

بعد ذلك يتم تخزين القيمة التي أدخلها المستخدم داخل المتغير `name`.

وبالتالي يمكن أن تكون الصياغة العامة:

```bash
read <اسم_المتغير>
```

مثال:

```bash
read name
```

ثم يمكننا استخدام القيمة الموجودة داخل المتغير:

```bash
echo "Hello, $name"
```

---

### 2-2.إظهار رسالة للمستخدم

في برنامجنا السابق توجد مشكلة بسيطة، وهي أن المستخدم لا يعرف ما الذي يجب عليه إدخاله.

يمكننا حل هذه المشكلة باستخدام `echo` لعرض رسالة قبل استخدام `read`:

```bash
echo "Enter your name:"
read name
```

وبالتالي سيكون السكريبت كاملًا:

```bash
#!/usr/bin/env bash

echo "Enter your name:"
read name

echo "Hello, $name"
```

وبهذه الطريقة سيظهر للمستخدم طلب واضح لإدخال اسمه.

---

### 2-3.استخدام `read -p`

في الحقيقة، يوجد أسلوب أفضل وأقصر لعرض الرسالة واستقبال القيمة في نفس الوقت، وذلك باستخدام الخيار `-p` مع `read`.

تكون الصياغة كالتالي:

```bash
read -p "Enter your name: " name
```

حيث:

- `-p` تسمح لنا بكتابة رسالة للمستخدم.
    
- `"Enter your name: "` هي الرسالة التي ستظهر للمستخدم.
    
- `name` هو المتغير الذي سيتم تخزين القيمة بداخله.
    

وبالتالي يمكن كتابة السكريبت كاملًا بهذا الشكل:

```bash
#!/usr/bin/env bash

read -p "Enter your name: " name
echo "Hello, $name"
```

وهكذا أصبح بإمكاننا استقبال قيمة من المستخدم وتخزينها داخل متغير ثم استخدامها لاحقًا داخل السكريبت.

---

## 3. تطبيق عملي

قم بإنشاء سكريبت يقوم بطلب المعلومات التالية من المستخدم:

- الاسم
    
- العمر
    
- البلد
    

بعد ذلك، استخدم هذه المعلومات لعرض فقرة تعريفية عنه

يجب أن تكون النتيجة بهذا الشكل:

```text
Hello, my name is "الإسم". I am "العمر" years old, and I live in "البلد"
```

### مثال على النتيجة:

```text
Enter your name: Ahmed
Enter your age: 53
Enter your country: Egypt

Hello, my name is Ahmed. I am 53 years old, and I live in Egypt.
```
