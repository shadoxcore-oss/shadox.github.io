# المدخلات
## 1.ما هي المدخلات :
هي ببساطة إستقبال قيمة من مستخدم بدل كتابتها داخل السكريبت مثال على ذلك برنامج يطلب من المستخدم إدخال رقم معين و بعدها يقوم بطباعة رسالة من نوعية `The numbers is X`

## 2.إستقبال مدخلات المستخدم :
خلينا ننشئ ملف بإسم `input.sh` و سنقوم بإعطائه صلاحيات التفيذ هكذا 

```bash
touch input.sh
chmod +x input.sh
```

- ملاحظة : يعد أمر `touch` من الأوامر مستعملة بكثرة عند رغبة بإنشاء ملف او عدة ملفات و صيغة الأمر بهذه الطريقة :

```bash
touch <namefile>
# أو 
touch <namefile1 namefile2 namefile3 ....>
```

المهم بعد ذلك نريد من السكريبت الخاص بنا أن يستقبل رقما من المستخدم و يقوم بعرضه يمكننا فعل ذلك كالتالي :

```bash
#!/usr/bin/env bash
read name
echo "Hello , $name"
```



- ملاحظة :  تقدر تستخدم أي محرر نصوص سواء كان `nano` و إذا تستخدم `nano` فتذكر:
- إختصار حفظ التغييرات `Ctrl+O`
- إختصار خروج من محرر نصوص `Ctrl+X`
